# 🍔 iFood Feedback AI

An interactive customer feedback analysis dashboard built with Python, Streamlit, Pandas, and Plotly.

## 📌 About the Project

iFood Feedback AI is a portfolio project designed to analyze customer reviews and transform feedback into useful business insights.

The dashboard allows users to explore customer satisfaction, identify common problems, and visualize sentiment patterns through interactive charts and indicators.

## 🚀 Features

- Customer feedback analysis
- Automatic sentiment classification using keywords and expressions
- Interactive dashboard with Streamlit
- Positive and negative feedback indicators
- Average customer rating
- Filters by sentiment and category
- CSV file upload for external feedback data
- Data visualization with Plotly
- Business recommendations based on negative feedback

## 🛠️ Technologies

- Python
- Pandas
- Streamlit
- Plotly

## ▶️ How to Run

Clone this repository:

```bash
git clone https://github.com/lucas-debrito-dev/ifood-feedback-ai.git
```

Enter the project folder:

```bash
cd ifood-feedback-ai
```

Install the dependencies:

```bash
pip install streamlit pandas plotly
```

Run the application:

```bash
streamlit run app.py
```

## 📊 Project Purpose

This project demonstrates practical skills in Python programming, data analysis, data visualization, and dashboard development.

**Note:** This is an educational portfolio project that uses sample customer feedback data. Sentiment classification is rule-based and uses keywords and expressions.
